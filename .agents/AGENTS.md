# PondFish Agent Workspace Rules

## Mandatory Rules for All AI Coding Agents

1. **Automatic Git Commit & Push to Main:**
   Whenever any code changes, edits, bug fixes, refactors, UI updates, or documentation files are modified/created in this repository, you MUST automatically execute `git commit` and `git push origin main` before completing the turn.

2. **Commit Message Format:**
   Commit messages should be concise, descriptive, and clearly explain the changes made (e.g., `feat(customer-app): rebuild home screen UI according to specification and design`).
